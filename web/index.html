Knappar på raden

Kör något i worktreen: package.json-skript (även i workspaces, t.ex. Metro i apps/mobile), make- och just-mål, deploy som känns igen (Firebase, Fly, Vercel) och egna actions. Överst finns dina workflows (flera steg i följd, t.ex. databas → backend → Metro; förloppet visas steg för steg) och längst ned GitHub Actions som kan startas för hand på branchen. Sök genom att skriva; Enter kör den första. ⚠ = deploy, migrering eller borttagning, som frågar först. Körs i ett eget tmux-fönster.
Egna actions: välj ✎ Egna actions längst ned i menyn. De sparas lokalt i ~/.config/devctl/actions/<repo>.yaml, aldrig i repot.

Övriga flikar

tmux
Alla sessioner, fönster och panes som karta eller träd. Skapa, döp om, dela, välj layout, lägg fönster under varandra och skapa lokala orkestratorfönster.
Servrar
Allt som lyssnar på en port: typ, process, repo och branch, och vilken pane som startade den. öppen = nåbar från nätverket, inte bara från datorn.
Docker
Containrar per projekt, med starta, stoppa, starta om och loggar.
Orkestrator
Chatt med den globala orkestratorn och listan över dess workers.
Automation
Local-Automation: dina schemalagda Claude-uppgifter, deras resultat och "Kör nu".

Allt uppdateras automatiskt: tmux, servrar och Docker varannan sekund, git var 10:e, PR:er varannan minut.
