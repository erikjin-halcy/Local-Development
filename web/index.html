Övriga flikar

tmux
Alla sessioner, fönster och panes som karta eller träd. Skapa, döp om, dela, välj layout, lägg fönster under varandra och skapa lokala orkestratorfönster.
Servrar
Allt som lyssnar på en port: typ, process, repo och branch, och vilken pane som startade den. öppen = nåbar från nätverket, inte bara från datorn.
Docker
Containrar per projekt, med starta, stoppa, starta om och loggar.
Orkestrator
Chatt med den globala orkestratorn och listan över dess workers.
Automation
Local-Automation: dina schemalagda Claude-uppgifter, deras resultat och "Kör nu".

Allt uppdateras automatiskt: tmux, servrar och Docker varannan sekund, git var 10:e, PR:er varannan minut.
